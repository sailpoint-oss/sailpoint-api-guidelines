This section contains the current rule set. Each rule category includes context and rationale to help you understand the "why" behind the requirements.

## How to use the Rules

- Each rule has a stable ID (e.g., `[#401]`) so you can cite it in reviews and deep-link to it.
- Rules are normative ("MUST/SHOULD/MAY"). Use the [Reference](/docs/appendices) section for checklists and recipes.
