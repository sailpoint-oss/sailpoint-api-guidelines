This section contains the current rule set. Each category is organized so you can quickly answer the practical implementation and documentation questions for that part of an API.

## How to use the Rules

- Each rule has a stable ID (for example, `[#use-http-methods-correctly]`) so you can cite it in reviews and link to it from any docs page.
- Rules are normative (`MUST` / `SHOULD` / `MAY`). Start with the category that matches your task; each rule includes a canonical example directly below its badge.
